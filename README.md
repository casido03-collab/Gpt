# Typing Kombat Telegram Mini App

Прототип мобильной игры для Telegram Mini App: игроки соревнуются в скорости набора русских слов, а правильно введенное слово запускает удар мечом и анимацию падения соперника.

## Что уже реализовано

- Главное меню с личным рейтингом, победами, лучшим словом, топом игроков и списком игровых сессий.
- Режимы запуска боя: с ИИ, с другом и случайный соперник.
- Боевая арена в стиле наброска: индикаторы здоровья, таймер, слова над обоими бойцами и поле ввода для телефона.
- Русский словарь для раундов печати.
- Анимация атаки мечом, вспышка попадания, получение урона, падение и автоматический подъем через 2 секунды.
- Интеграция с `window.Telegram.WebApp`: приложение сообщает Telegram, что готово, и разворачивает Mini App при запуске внутри Telegram.
- Локальное хранение рейтинга, побед и лучшего слова через `localStorage`.

## Запуск локально

```bash
npm run start
```

Откройте URL, который прокинут вашей средой разработки для порта `5173`. При локальном запуске на своем компьютере можно открыть `http://localhost:5173`.

## Проверка JavaScript

```bash
npm run check
```

## Что нужно для настоящего мультиплеера

Текущий прототип показывает UX и клиентскую механику. Для реальной игры с другом или случайным игроком нужен backend:

1. Telegram авторизация и проверка `initData`.
2. WebSocket-сервер для матчмейкинга, дуэлей по ссылке и синхронизации слов/ударов.
3. Серверная валидация скорости ввода и результата раунда, чтобы защититься от читов.
4. База данных рейтинга, истории боев и таблицы лидеров.
